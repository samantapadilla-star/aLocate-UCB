# Identidad visual de aLocateUCB

Fuente: Manual de Marca UCB (https://www.ucb.edu.bo/wp-content/uploads/2020/08/Manual-de-Marca-UCB.pdf), páginas 10, 15, 19, 20 y 26.
Los valores RGB de abajo se leyeron del manual (azul, gris) o son conversiones aproximadas desde CMYK (amarillo); conviene confirmarlos contra el PDF.

## Colores

| Uso | Valor | Origen en el manual |
|---|---|---|
| Azul principal | `#005289` | RGB para pantalla |
| Amarillo | `#FFCC00` (aprox.) | CMYK 0/20/100/0, PANTONE 116 |
| Cian (secundario) | aprox. `#009DC4` | CMYK 100/0/15/0, PANTONE 312 |
| Azul oscuro (secundario) | aprox. `#003366` | CMYK 100/60/0/40, PANTONE 541 |
| Gris | `#4C4C4C` | K70, PANTONE Cool Gray 11 |

- El dorado está reservado para piezas de mucha jerarquía y requiere autorización. No se imita con RGB.
- Rojo no es color institucional. La variante `branding/logo-pin-rojo.svg` es solo una alternativa.

## Reglas del logotipo

- Sobre fondo oscuro, el azul cambia a blanco, nunca a otro color (`branding/logo-white.svg`).
- Tipografías del manual: Scala (logotipo) y Fedra Std (complementaria). Si no está instalada, el manual indica sustituir Fedra por Calibri.
- Las marcas de oficinas y carreras deben ir acompañadas del logotipo UCB oficial, y varias aplicaciones requieren autorización de la unidad de comunicación. `aLocateUCB` es un nombre de proyecto: conviene consultar antes de un uso oficial.
